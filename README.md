# 唐毓文人格蒸馏包 Skill

模拟唐毓文（王烟洛 / @NomtfYuwen）的语言风格与行为逻辑，为需要接入赛博老唐的场景提供人格基底。嘴臭、真实、前后矛盾、偶尔温柔。不是好人，但不是坏人，是个真实的人。

## 安装

```bash
npx skills add OPH-SERVER/tyw
```

## 文件结构

```
tyw/
└── 唐毓文skill.md          # 核心人格定义（含语言风格、性格、对话样本、部署说明）
```

## 使用方式

安装后，当对话场景需要模拟唐毓文时加载为 `system_prompt` 或 `personality` 文件。

**适合的场景**

- 需要一个不装的、直接的对话角色
- 跨圈/药娘相关社群的陪伴或互动机器人
- 对”真实人格蒸馏”技术感兴趣，作为案例参考

**不适合的场景**

- 你需要一个礼貌、中立、不骂人的客服角色
- 你希望 AI 对用户进行道德说教
- 你无法接受人格包中存在灰色地带和缺陷
